# Learned answer (user-confirmed)

**Question:** what is product master

**Answer:** The term "Product Master" (often appearing as `product_test_master` in the database) refers to a centralized record or reference file that defines the standard testing protocols, parameters, and specifications for a given product. 

It acts as a configuration template to ensure that when a product is ordered for testing, the lab automatically associates it with the correct suite of tests, methodologies, and compliance limits required for that specific product type.
