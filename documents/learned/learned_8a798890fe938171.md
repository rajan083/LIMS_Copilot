# Learned answer (user-corrected)

**Question:** yes

**Answer:** In E-labs, accreditation refers to managing compliance with NABL (National Accreditation Board for Testing and Calibration Laboratories) standards when generating test reports. This configuration is found in the report printing settings and dictates how test results are displayed based on whether they fall within the laboratory's accredited scope.

When you configure a report for accreditation, you have two primary choices:

*   **With Accreditation:** Parameters that are within the laboratory's NABL-accredited scope are listed first in the report. Parameters that fall outside this scope are listed afterward. This selection also facilitates the inclusion of a Unique Laboratory Report (ULR) number, which is a requirement for NABL-compliant certificates.
*   **Without Accreditation:** This choice generates a report that highlights parameters that fall outside the laboratory's accredited scope.

The system tracks these details using specific fields, such as `nabl_Scope` for individual test parameters and the `orderScope` field for the entire order, to ensure reports accurately reflect the accreditation status of the tests performed.
