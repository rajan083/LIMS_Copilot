i) Assign to my team- If you are reporting manager of your assignee then you can see all the assigned tasks of your assignee in this tab. Also, you will see status of all the tasks.
ii) Assign to me- if you want to see your assigned tasks only then you can see them here. There is also provision to update the assigned tasks from this.
iii) Open task- All tasks can be found here except with the status of done. If you update the task from this tab, then the reporting manager and assignee will receive a mail.
iv) Closed task- Only those tasks with the status of done will be visible here.
