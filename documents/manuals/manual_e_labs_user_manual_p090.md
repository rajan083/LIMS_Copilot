Figure: A dialog box titled "APP ROLE BINDING". It displays an "Assigned Type" of "appUserGroupOfGroup" and an "App User Group Of Group" field. Below is a table displaying assigned types and associated users. Beneath the table is a section labeled "App Role List" with checkboxes for the following options:
Option: APP ROLE FOR FINANCE.
Option: APP ROLE FOR testr.
Option: Admin.
Option: App Role For Permission Module.
Option: Client Module-FullAccess.
Option: Request Module-UserAccess.
There is a blue "UPDATE" button at the bottom right.

Roles, which you are already created in App Role template tab those all are visible in App Role List. Here you can select the role which you want to bind with the user, user-group or user group of group.

Basically you can create user, user-group or user’s group of group and then create role. Give permissions different tabs and modules according to the role. Now that role will be bind to any user, user-group or user’s group of group. Through this all the permissions which is given to that role will be allocated to user, user-group or user’s group of group.
