E-labs User Manual, page 107. Source file: E-labs User Manual.pdf.

If you want to reject any customer travel plan then click on rejected customer checkbox then mention reason in rejection comment field. If you want to approve or reject the whole travel plan then go to the status dropdown and set the status accordingly.

Figure: TRAVEL APPROVAL popup. Status dropdown showing option: Approved. Comments field populated with "Approved". Checkbox: Rejected Customer.

Now in this case travel plan status change to Approved which you also can see in below image.

Figure: Travel plan dashboard list showing various TRP IDs with status updated to Approved for one entry, while others remain as Submitted.

But when you click on edit icon and the popup appears then you can see the approved or rejected list.

Figure: TRAVEL MANAGEMENT popup window displaying "Approved Customer List(1)" and "Rejected Customer List(1)". Contains fields: Plan Date, Return Date, Add Booking Request, Associated Travel Plan, Associated Sales Member, Recorded Sales Member. Status displays: Approved.
