To add product under product category, the user should click on the Add button and a popup appears.
Figure: Dialog showing a "Category" tree structure with "Elect Dept", "Food", "Pharma" (containing "Rawmaterial" and "Tablets"), "Medicine", "Finish GOODS", "Soil Dep", and "Textile".
Figure: Popup window titled "PRODUCT/SAMPLE" with fields for "Sample Name", "Category" (with "Tree View" link), and "Status" (set to "Active"). There is a button labeled "UPDATE".
In this window you can give a product or sample and select a category by clicking Tree View option. Also, set the status as active and then the user can click on the save button for saving data.
