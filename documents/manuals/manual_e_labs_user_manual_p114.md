Step 1: Remarks- If the finance person not approved full amount then mention remarks in this field.

Once it is approved either full or partial then it will go to the payment release tab where the payment release person can select the mode whether it is Online, Cheque or Cash.

Figure: Screenshot of the "PAYMENT MANAGEMENT" popup dialog. Fields include "Date", "Mode Of Travel", "Price In Km", "Distance In Km", "Local TA", "Travel Fare", "Dearness Allowance", "Food", "Hotel", "Parking", "Toll Charge", "Miscellaneous", "Summary", "Total For The Day", "Total Amount", "Approved Amount", and "Remarks". A "Payment Mode" dropdown is shown.

Once you select any mode then some of the relevant fields will appear.
Step 2: If selects Online then Transaction ID field will appear.
Step 3: If selects Cash then Voucher Number field will display.
Step 4: If selects Cheque then Cheque Number and Bank Name fields will appear.

Fill all the necessary details and once this will update on the user’s dashboard.
