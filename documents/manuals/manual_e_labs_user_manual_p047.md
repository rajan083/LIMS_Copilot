10 What Are the Steps for Reviewer?

Stage 6-

Now, on the reviewing stage reviewer can review it by clicking on review report icon then the following screen will appear.

Figure: Screenshot of the "REVIEW REPORT" window showing order details and "Part A: Particulars Of Sample Submitted". Fields: Sample Reg No; Sample Reg Date; Report Date; Report No; NABL CLR No; Customer Ref No; Letter Dated; Nature Of Sample; Grade/variety/type/class/size/etc. Buttons: UPDATE; CONFIRM.

In the reviewing stage, we will display the complete order and the respective parameters selected were selected in that order. If any parameter which comes under that order is not being tested yet or the result was entered the order will not be visible on reviewing stage.

Figure: Screenshot of the "REVIEW REPORT" window showing "Group & Discipline" and "Test Parameter(3)". Table columns: Parameter Category; Parameter; Unit; NABL Scope; Equipment; Method; Std Value From; Std Value To; Result. Buttons: UPDATE; CONFIRM.
