16 When Can I Use Report Amendment Option?

Step 11: We only need a Report Amendment tab when the order is in invoice stage and a customer says there is an error with the result or the order so we will use this choice to correct that error i.e., Report Amendment. Click on the update icon in the Report Amendment section. This will open the following screen.

Figure: EXCEPTIONAL REPORT AMENDMENT dialog box. Fields include Product Material Name, Product Material Parameter, Error Details, Correction Details, and Corrective Action. Buttons: Save, Update. It illustrates the fields required to document and fix errors in an existing report.

Error information and correction information will be stored here for correction. When the user clicks the save button, after the correction made for the order returns to the reviewing step, the user will select the “Amendment Required” dropdown and then update it.

So, this is how we can deal with any sequence from ten steps.

Note:- User can use amendment option when the order is in invoice stage. When it is in dispatching stage you can’t use amendment option. Once you done amendment it will return to the reviewing stage.
