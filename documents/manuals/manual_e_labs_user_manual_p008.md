3 Requirements

3.1 Minimum Server Requirements
• Microsoft Windows 7
• RAM 32 GB +
• 8 Core Plus
• MAC OS X 10.4 or later
• Internet Connectivity
• 1 x USB port

3.2 Minimum PC Requirements
• Microsoft Windows 7 / Vista / XP SP2
• MAC OS X 10.4 or later
• Internet Connectivity
• 1 x USB port

3.3 Supported Web Browsers
• Mozilla Firefox
• Google Chrome
