E-labs User Manual, page 62. Source file: E-labs User Manual.pdf.

In Customer Information section, select company name then the information regarding this customer will auto populated. In quotation letter drop down select quotation against this customer. Once you select the quotation you can see all the club quotations against this selected quotation. You can take idea from below image.
For all the club quotations go to Select Quotation section which comes under Sample & Test Information. Click on the ‘+’ icon which is highlighted in the above image. After clicking on this icon following popup will appear.
