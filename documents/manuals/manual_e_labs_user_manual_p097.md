E-labs User Manual, page 97. Source file: E-labs User Manual.pdf.

Once you click on save button as many orders will be generated as the number of parameters selected. It means if the total parameters are twenty then for each single parameter twenty orders will be generated.

Next step is for the Job Allocation, go to Job Allocation menu.

Figure: Screenshot showing the "Job Allocation" interface. Menu items visible include: Home, Testing & Review, Sample Receipt, Sample Master, Job Booking. The grid displays columns: Time, Job No., Buyer's Name, Customer Contact Person, Customer Address. Below this is another grid showing columns: #, Job No., Sample Description, Test Parameter, Test Method/ Test Condition, Reference Test Standard, Priority, Report Due Date.

Under this menu, you can see four different sub menus. Allocation and Assigned are the same which you can refer from the Order Process Management module. TDS option starts from the Parameter v/s TDS submenu.
