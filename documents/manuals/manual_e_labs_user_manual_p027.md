When user selects Company name and Contact list the details of the contact person and company will be auto reflected.

Figure: ENQUIRY MASTER dialog window. Fields: Address; Company Name; Sec/Id & Industrial Area; Gomtinagar Nagar; India; State; City; Zip Code; Sales Executive; Products & Tests Detail; Branch; Experiment; Department; Reference Test Standard; Enquiry Detail; Button: FILE UPLOAD.

In the Products & Tests Detail section, users must enter sample and its query details.
• Branch- Select the branch where you receive this enquiry.
• Department- To which Department does it belong.
• Sample name- Name of the sample.
• Reference test standard- Mention test standards for the sample.
• Query Detail- Sometime user send any photo or pdf file regarding query details then you can upload here by clicking on File upload button.
• Status- Status changes according to the enquiry stage which is mentioned below.
a) When user creates new enquiry then the status will be New.
