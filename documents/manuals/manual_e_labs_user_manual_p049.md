11 What Happens on The Finalizing Stage?

Stage 7: When the reviewer confirms this then this will go to the finalizing stage. Here finalizer has also complete view of report by clicking on review report icon.

Figure: Screenshot of the "Finalizing Reports" list screen. The interface shows a data table with columns: Branch; Department; Sample Registration No; Sample Date; Sample Condition; Customer Details; Report Name. Visible buttons include an icon for "Review Report". The navigation menu on the left lists: Master; Customer; Admin; Order Management; Packet; Sample Registration; Scheduling; Testing. This illustrates the list of reports awaiting finalization.

When the finalizer opens this report then the following screen will appear.

Figure: Screenshot of the "FINALIZING - REPORTS" dialog box. The table shows columns: Param Category; Parameter; Unit; NABL Scope; Equipment; Method; Selector; Std Value From. At the bottom, there is a "Revert" checkbox and a "Confirm" button. This illustrates the view and action options available to the finalizer.

Here, if the finalizer is satisfied with this report, then can directly click on the Confirm button but at this stage, finalizer cannot edit anything. If not satisfied with this result, then click on revert checkbox when you can click on revert.
