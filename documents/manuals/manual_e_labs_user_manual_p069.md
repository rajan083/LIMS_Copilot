Once you fill all the necessary details set the status by selecting section in charge from the status dropdown so that it can go to the next stage that is section in charge. It will now go to the section in charge in review stage.

Figure: Screenshot of a "Test Result" web form. Fields include: Remark; Equipment Detail; Specimen Orientation; Hammer Capacity (Nm); Specimen Length; Part C; Test Method: Standard Nominal Test Verified; Sample Des; Additional Treatment; Type Of Result; Severity Of Impact; Section In Charge (dropdown).

Rest of the steps are same from the Order Process Management only the difference is user can set the status from the dropdown after reviewing it. From the status dropdown user could be select one stage back or one stage forward.
