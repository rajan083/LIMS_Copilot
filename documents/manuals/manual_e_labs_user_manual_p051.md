12 What Happens on The QA Approval Stage?

Stage 8: Now in QA Approval phase, QA can also review this report but there is no choice for QA to edit details. QA can only return or confirm this report.

Figure: Screenshot of the "QA APPROVAL" list screen. The interface shows a table with columns: Select; Sample Registration No; Department; Sample No; Barcode; Sample ID; Sample Date; Download. Navigation menu on the left lists: Master; Customer; Admin; Order Management; Packet; Sample Registration; Scheduling; Testing. This illustrates the queue for QA approval.

When QA reviewing this report then the following screen will appear.

Figure: Screenshot of the "QA APPROVAL - REPORTS" dialog box. The table columns are: Param Category; Parameter; Unit; NABL Scope; Equipment; Method; Detector; Std Value From. Below the table are fields: "Revert" (checked); "Comment"; and a "Confirm" button. This illustrates the QA review and approval dialog.

Here QA can check on revert checkbox and give a comment for this. When QA reverts to this then it will go back to step one i.e., Finalizing. Once QA confirms this, it will be ready for the invoicing phase. Also, QA can publish the report.
