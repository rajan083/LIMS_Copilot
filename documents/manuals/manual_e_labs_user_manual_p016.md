This is the part where basically all the equipment for testing in the lab should be included. For this, click on the Add button and a popup screen appears.
Figure: Popup window titled "EQUIPMENTS" with fields for "Name", "Equipment No", "Make", and "Status". There is a button labeled "UPDATE".
Name- This is the field for the equipment’s name.
Equipment No- This is the serial number for any equipment.
Make- When was the equipment made.
Status- Select active if the equipment is currently active.
5.4 Methods?
The details of the method and the tools that can be used to test that method. Such information can be stored in this section under the method name. The user should go to the Method tab and then click on the Add Button.
