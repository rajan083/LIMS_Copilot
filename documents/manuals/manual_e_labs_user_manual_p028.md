6.4 Quotation?
Quotation Letter- When the enquiry is being generated then we can create the quotation for the client. For this, first click on quotation then Add button.

Figure: PLACE NEW QUOTATION dialog window. Fields: Select Enquiry; Customer Detail; Category Name; Customer Name; First Name; Last Name; Email; Mobile; Address; Address Line 1; Address Line 2; Pincode; State; City; Sales Executive.

Select enquiry here for which you want to make quotation. Once you select enquiry all the details related to that enquiry will be auto populated.

Figure: PLACE NEW QUOTATION dialog window. Fields: Products & Tests Detail; Product; Sample Name; Reference Test Standard; Branch; Checkbox: Product Wise Pricing; Select Parameter(s); Param Category; Parameter; Measuring Unit; Equipment; Time Taken; Method; Detector; Test Scope; Amount Details.

Note: - The product name and sample name may be different. If you have already created product master with the same parameters, you can use it in the product field. There is no need to create a new product test master.
