5.5 Parameter Category?
As the user adds the Product category, the Parameter category will be added to this section. Go to this tab then click on the Add button.

Figure: Parameter Category dialog box.
Field: Name; Value: 10G Optical Ethernet.
Field: Department; Value: Elect Dept.
Field: Status; Value: Active.
Button: UPDATE.

In the image above, the user can fill in all the required information.
Name- Name of the parameter category.
Department- Which department does this category belong to.
Status- Set active if it is currently in use and set inactive if not.

Once the parameter class is saved, the user can switch to the Test parameter details tab. Click on the Update button.
