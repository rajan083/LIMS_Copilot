20 Permission Module?
Permission module is the feature in our software through we can control full permission for user group, group of group and for any role.

20.1 Where To Navigate To Use Permission Module Features?
Step 1: Go to Identity And Access Management then click on User tab.

Here you can see six menus. The menus which are used for permission module those are highlighted in the above picture.

Figure: Screenshot of the "Identity & Access Management" user table. It shows a grid with headers: Action, Name, App User Email, Department, Role, and Modules. The grid contains multiple rows of user data. A search box is visible at the top left. A sidebar menu on the left lists: Identity & Access Management, User, OHC APP New, and Role Management.

20.2 What is App User Group and How To Create It?
Here you can create the group of users in which you can add many employees which you want to add in this group.
