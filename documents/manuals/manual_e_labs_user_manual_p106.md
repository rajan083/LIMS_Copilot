E-labs User Manual, page 106. Source file: E-labs User Manual.pdf.

Manager can see details on dashboard in the approval module you can see in below image.

Figure: Approval Module dashboard showing a list of travel plans with columns: Icon, Plan ID, Name, Designation, Date, Status, Action. Visible statuses: Submitted. Navigation sidebar items include: Travel Management, Account Info, Sales Management, Travel Approval, Business Relationship Management.

Created travel plan will be approved by senior. For any approval or rejection click on the edit icon first a popup will appear with the details of travel plan.

Figure: TRAVEL APPROVAL popup dialog. Fields: Plan Date, Return Date, Booking Request (Option: Add Booking Request), Purpose, Comments. Customer List For Plan Approval(2) list shows: Address, Customer Name, Current Revenue Amount, Growth Per, April, May, June, July, Contact Person Name, Department.

Now, click on highlighted icon which is shown in above image. From here you can approve or reject the travel plan according to the customer wise.

Figure: CUSTOMER LIST FOR PLAN APPROVAL (2) section showing details for each customer: Customer Name, Address, Department, Designation, Email, Purpose Of Visit, Associated Lab Name For Testing, Rejection Comment, Rejected Customer. Buttons: Save, Cancel.
