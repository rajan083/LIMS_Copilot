E-labs User Manual, page 110. Source file: E-labs User Manual.pdf.

Figure: Travel Report popup window. Fields include: Travel ID, Travel Date, Actual Travel Date, Actual Return Date, Checkboxes: Travel Claim Required, Is Travel Claim Required. Approved Customer List For Travel Plan(1) table with columns: Customer Name, Address, Contact Name, Departments, Designation, Number, Email. Rejected Customer List table. A button labeled "SAVE" is at the bottom right.
Once you clicked, following screen will appear where you have the provision to edit some fields.
Figure: APPROVED CUSTOMER LIST FOR TRAVEL PLAN(2) table with columns: Contact Name, Travel Plan, Customer, Status, Comment By Sales Executive, Is Travel Claim Required, Associated Lab Name For Testing, Action (with edit icon).
Step: Contact Name- If user want to change existing contact person name then he/she can do this.
Step: Comment By Sales Executive- User have to update the feedback given by the customer.
Step: Status- On the basis of the comment of the customer user have to fill whether your visit is Cancelled, Completed, Not Completed or there is any requirement to Rescheduled it.
Step: Is Travel Claim Required- If you want to claim any expense for this relevant travel plan then click on checkbox. Once you clicked it Travel Claim section will show on the screen.
