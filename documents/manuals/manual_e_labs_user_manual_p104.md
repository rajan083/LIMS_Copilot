Select Customer List -
In this section, we have two provisions either is for new customer or for existing customer. User can define travel plan for new customer and also for existing customer.

Figure: Screenshot showing the "CREATE TRAVEL PLAN" window focusing on the "Select Customer List" section. It displays a list of customers with columns: Customer Name; Address; Contact Person Name; ITC Department Name; Designation; Number; Email; Sample Type.

In Case Of Existing Customer- If user selects existing customer then all the data of existing customers from the database will visible on screen. You can see in the below image.

In the above screen user can select number of customers according to the requirement when user selects any checkbox then some details auto reflected and few details user must fill which are already explained below.
Department Name- For which department user want to create travel plan.
Purpose Of Visit- Reason of visit fill here.
Associated Lab- If any lab is already working with the visited customer then name of the lab must be mention here.
