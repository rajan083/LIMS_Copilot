E-labs User Manual, page 48. Source file: E-labs User Manual.pdf.

Here the details are already filled which were entered by the order booker and the result section was entered by the test analyst. If the reviewer wants to change something, then the reviewer can edit these details. In the Note textbox, any abbreviations which can be used for parameters that can be given here and in the remarks dropdown reviewer can select any remarks according to its result.

Also, if the reviewer is not satisfied with the result, then that user will also revert this. For this, click on + icon which shows the right of the test parameter then the following screen will appear.

Figure: Screenshot of the "TEST PARAMETER(3)" popup window. Table columns: Parameter Category; Parameter; Unit; Method; Std Value From; Std Value To; Result; Review; Comment. Buttons: RESET UPDATE; TEST PARAMETER; CLOSE.
Option: Checkbox in the "Review" column.
Option: + icon button in the "Review" column.

Now click on review checkbox and give a comment then Confirm by clicking on this button. If the reviewer reverts it will go to the section in charge by default but if the reviewer wants to revert it to testing stage, then it is configurable according to your requirement.
