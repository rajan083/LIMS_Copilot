19.5 Rename Or View Details?
When you upload any file you have the option to view their details and also rename file. For using these two options click on that file then go to rename file or view details same as which will be given in the following picture.

Figure: Screenshot of a file icon being selected with an arrow pointing to a vertical three-dot menu icon. The menu displays the following options:
Option: Rename.
Option: View details.

Same for downloading any file. Select that file then go to three dots you can see download option click on that. The file will be downloaded in your system.
