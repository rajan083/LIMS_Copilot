4.1 Create a New Account?
When the user clicks on the "Create New Account" option, the following screen will be displayed, they will need to provide all the necessary information.
Figure: A "Sign Up" form containing the following fields: "Full Name *", "Email address *", "Password *", "Confirm Password *", and "Mobile *". At the bottom, there is a disabled "Sign Up" button and a link labeled "Already have account? Log In".
Once registered, the user can login to their account with their credentials.
