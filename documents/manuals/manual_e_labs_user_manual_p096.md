E-labs User Manual, page 96. Source file: E-labs User Manual.pdf.

Figure: Screenshot of the "Login Register" table showing entries for customers including columns: Action; Date; Time; Login As; Customer Details/Buyer's Name; Customer Contact Person; Customer Address. It highlights an "Add" button.

As the above picture shows click on Add button so that you can book the order. After clicking on this you can see following popup.

Figure: Screenshot of "PLACE NEW ORDER" popup. Section "Customer Detail" contains: Sample Booking Reference No; Select E-TRF; Customer Name; Address Line 1; Address Line 2; State; Country; Pincode; Contact Person Name; Last Name; Designation; Email; Mobile No; Tel. Section "Sample Detail" contains: Order Date; Priority; Remarks; Extra Amount.

Once you select the sample from the dropdown the details will auto populated of the customer. Now you select E-TRF, only those E-TRF against which the order has not been booked will appear. Once you select E-TRF in dropdown all parameters against selected E-TRF will auto populated in Select Parameters section in the grid.

Figure: Screenshot of the "PLACE NEW ORDER" popup displaying "Invoicing Details" section with fields: Company Name; Company Address; Contact Person Name; Contact Person Email; GST No; Mobile No; Fax. Section "Sample & Test Detail" includes: Order Booking Type; Select Parameter; and an "UPLOAD IMAGE" button.
