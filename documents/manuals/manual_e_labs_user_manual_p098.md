Note:- For each parameter we have already created forms and for every parameter there is a different form. That forms will be known as TDS (Test Data Sheet).

21.3 How To Use TDS Option For Order Booking?
Go to Parameter v/s TDS submenu. Here I am taking the example of “Izod Impact Strength” test parameter. Click on edit icon below popup will appear on screen.

Figure: Screenshot of the "PARAMETER VS TDS" popup dialog. It contains fields: Name (text input "Izod Impact Strength 23°C, 80*10*4mm cut"), TDS Form (text input "FRM 002"), and an "UPDATE" button. An arrow points to the edit icon.

From the above image, you can see parameter name and fill TDS form against this parameter. This is only one time work for every parameter. Once you saved this you don’t have need to set this again and again.

Note:- If no TDS form is selected with any parameter, then common TDS form will be automatically mapped from it.

21.4 Testing Stage?
