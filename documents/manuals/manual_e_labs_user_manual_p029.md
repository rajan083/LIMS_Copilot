E-labs User Manual, page 29. Source file: E-labs User Manual.pdf.

Product and sample names can differ just as generic names can. To test any parameters, you can assign parameters by clicking the + sign in the Select Parameters section. The popup screen appears, and you can provide the desired parameters.

Figure: Place New Quotation dialog box. Field: Amount Details. Field: Tax Information. Field: GST. Field: Total Amount. Field: Sampling Charges Will Be Extra If Applicable. Option: Yes. Option: No. Field: Purpose Vs Cost. Field: Purpose. Field: Cost. Button: Add. Button: Close.

If you have applied for some discount in your parameter list, then the details will be displayed in amount details. Then, you can select the sampling charges option if there is any additional charge you wish to include. After this user can proceed by clicking on Add button for saving these details.

Figure: Quotation data table screen. Menu items: Home, Account, Contact, Enquiry Master, Quotation, Customer PO. Filter fields: Action, Quotation Letter No, Quotations, Branch, Department, Company Name, Contact. Buttons: Filter icon, Add, Download.
