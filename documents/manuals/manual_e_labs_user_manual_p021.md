5.8 Reference Test Standard?
Users can add Reference Test Standards based on specific test standard descriptions, such as British pharma or Indian pharma. This allows them to modify the testing process according to their preferred pharma.
• Reference test standard/Reference protocol- It is the test standard according to some specific regularities which you want to choose for your parameter testing.
• Test standard description- It is the book’s name which you want to choose for testing.
• Department- For which department do you want to use these test standards.
