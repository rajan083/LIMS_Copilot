E-labs User Manual, page 77. Source file: E-labs User Manual.pdf.

E-Labs

Now admin will have to fill all the necessary details like:
Name- Name of the user.
Short Code- We can create short code for any user through which we can know about the user’s activity.
Email- Registered email of the user.
User ID- Registered email and user id will be same.
Branch- In which branch does this user work select accordingly.
L1 Manager- User's reporting manager will be mentioned here.
L2 Manager- If there are two reporting managers of the same user, we can mention it here.
Associated Account- Mention companies here for which user works.

There are some checkboxes also in which few of them I'll explain below-
Is Sales Person- If the user belongs to sales profile, then check this checkbox.
Is Commercial Coordinator- If the user belongs to commercial coordinator profile, then check this checkbox.
Is Sampler Person- If the user belongs to sampler person profile, then check this checkbox.

Extra User Role:
If the user belongs to some other role, you can check the checkbox accordingly.
