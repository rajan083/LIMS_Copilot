Whenever user creates a new folder there is a need for permissions to access the folder. Without setting permissions you cannot access this new folder same message you will see which is shown in below image.

Figure: Dialog box titled "NEW FOLDER". It contains a text input field labeled "Doc1", a "Cancel" button, and a "Create" button.

19.3 How To Give Permissions To Access New Folder?
For setting permissions click on the folder which you have just created now user can see below image.

Figure: Screenshot showing a folder named "Doc1" selected within the Document Library. An arrow points to a notification box labeled "Create and Upload Permission no available".

Click on permissions option a dialog box will be appear in which you can set permission to any user. For saving this, click on Add and then Save button.

Figure: Screenshot showing the file management toolbar with a menu containing the option "Permissions".
