Here are the key details to fill in. We will explain some of them to you.

• Assignee Name- To whom you want to assign the work. Once you select the assignee's name, the reporting manager with that assignee will auto populate.
• Project- Mention here the project for which you are creating this task.
• Component- Mention here which part the user should work on for this task.
• Issue type- Is it a bug, story, or task, select here.
• Task start date- Select the date when you start work on task.
• Task due date- Select date when you will complete task.
• Status- Select status according to the task stage.
• Summary- Give a summary for your task.
• Description- Give in detail an explanation of task in the description field.

Once you save the task assignee and reporting manager will receive a mail for this saved task.
