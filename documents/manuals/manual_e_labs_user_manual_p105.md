In Case Of New Customer- If user selects new customer then all the details fill manually.

Figure: New Customer dialog box containing fields for: Customer Name, Address, Contact Person Name, TC Department Name, Designation, Email, Mobile No, Purpose Of Visit, Associated Lab Name For Testing. The dialog includes a Customers(1) list displaying Customer Name: PACE BIOTECH; Address: NEHRU ROAD,VILL SUR; Contact Person Name: MR ABHISHEK TYAGI; Department Name: Pharma; Designation: -; Number: 9899401811; Email: pacetech@gmail.com. Buttons: Add Record, Save.

• Customer Name- Name of the customer.
• Address- Location's address.
• Contact Person Name- With the selected customer assigned contact person name must be mention here.
• Department Name- Select the department for which you are visiting.
• Designation- Fill your designation.
• Purpose Of Visit- Mention the reason of visit.
• Associated Lab Name For Testing- If any lab is already working with the visited customer then mention here.

Now, click on Add Record button. User can also add number of new customer through this same process. After you can add customers according to your requirement then click on Save button for creating this travel plan.

Status of the travel plan will be set to Submitted and this will be visible on the dashboard of the approver for the approval purpose.
