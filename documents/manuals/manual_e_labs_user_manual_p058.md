15 What Are the Steps for Dispatching Stage?

Step 10: Here the order is ready for dispatching. Click on the dispatch icon then the following screen will appear.

Figure: REPORT DISPATCH dialog box. Fields include Order No, Docket No, Docket Date, Dispatch Date, Dispatch Vendor, Dispatch Number, and Description. Button: Confirm. It illustrates the interface used to input dispatch details for an order.

Here, the order number is auto populated in this, and the user must fill in all the other necessary details then click on the Confirm button.
