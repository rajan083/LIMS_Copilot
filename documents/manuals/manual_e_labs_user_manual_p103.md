E-labs User Manual, page 103. Source file: E-labs User Manual.pdf.

Figure: Screenshot of the "CREATE TRAVEL PLAN" popup window. Fields: City (dropdown); Travel Date (date picker); Return Date (date picker); Ticket Booking Required (checkbox); Hotel Booking Required (checkbox); Associated Sales Member (dropdown); Select Customer List (button). On the right side, it displays a list of customer details including Name, Sales Executive, Status, and Last Visit date.

User will have to fill in all the necessary details.
City- User can choose the city where he/she wants to travel.
Note: - On the selection of city, all the relevant customers with logged in user will be displayed on the right side of the screen.
Travel Date: - Date of travel.
Return Date: - If travelling takes more than one day then mention return date also.
Ticket Booking Required: - If the user is looking for tickets, then select this checkbox.
Hotel Booking Required: - If a user is looking for a hotel booking then select this checkbox.
Associated Sales Member: - If the person wants any other person to come with them, select the name in this dropdown.
