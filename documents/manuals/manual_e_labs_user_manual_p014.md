In this screen you are going to add a product category, for example- under pharma there are three categories like finished goods, raw materials and other.
Figure: Popup window titled "PRODUCT CATEGORY" with fields for "Name", "Parent", and "Status". The "Parent" field has a "Tree View" link. There is a button labeled "UPDATE".
When the user clicks on the Tree View option, the screen shown below appears.
Figure: Tree view dialog showing a hierarchical list with expandable nodes: "Elect Dept", "Food", "Pharma" (containing "Rawmaterial" and "Medicine", which further contains "Acarbose Tablet"), "Finish GOODS", "Soil Dep", and "Textile".
Here you can choose a parent for the product category using this option. Now if I take the example Pharma-finish products-tablet-paracetamol. There is paracetamol product, tablet is product category which comes under finished goods and pharma is department. So, this creates hierarchy here.
