E-labs User Manual, page 32. Source file: E-labs User Manual.pdf.

Figure: Customer PO dialog box. Field: Customer Name. Field: Contact Name. Section: Billing Information. Fields: GST No, Tax Type, Address. Button: Upload PO. Section: Items. Fields: Item Name, Qty, Rate, Cost, Total. Buttons: Add, Close.

You can enter the customer's name and contact details here.

• Billing Information- GST No: If you have given GST No. then tax type will be auto selected.

• Tax Type: If you have not been given GST No. then you can type manually. Other details can be filled out here.

• Items- The items for which you want this PO to be generated, enter the details in this section.

• Amount Details- Details will be automatically calculated once all the details are filled in.
