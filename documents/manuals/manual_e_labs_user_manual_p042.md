E-labs User Manual, page 42. Source file: E-labs User Manual.pdf.

Fill all the necessary details here, like:

Department: Select the department which this belongs to.
Group Name: Select the name of the group which this belongs to.
Test Analyst: Select the test analyst which you want to allocate then all the equipment will be auto populated.
Test Parameter: Click icon which is on the right of test parameter section. Parameters list will be showing, and the user can select checkboxes according to which parameters user want to allocate.

Figure: Allocation dashboard screen showing tabs for Allocation, Assigned, Expected due date change, and Modify Order Details. The grid displays columns for Action, Branch, Department, Customer Name, Place, Sample Registration No, Sample Registration Date, and Product.

In this module, some of the tabs are showing i.e.:

Allocation: Allocating parameter for its testing to their analyst here.
Assigned: User can see assigned list of parameters to their analysts.
Expected due date change: If an order has two parameters one takes four days and other is taking six days to get a test done then expected due date will be showing six days from its order booking date.
Modify Order Details: User can also change his order details or parameters in order by going to this tab then clicking on Add button. Then the following screenshot will appear on screen.
