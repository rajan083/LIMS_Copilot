E-labs User Manual, page 46. Source file: E-labs User Manual.pdf.

If the section in charge is not satisfied with the result, then the section in charge will have to click on + icon which is on the right of the review result parameter list.

Figure: Screenshot of the "REVIEW RESULT" popup window showing parameter details. Table columns: Parameter; Std Value From; Std Value To; Equipment name; Running Time; Result; Send Modification; ID Comment. Buttons: REVIEW RESULT; NEVER PROVIDE RESULT; DONE.
Option: Checkbox in the "Result" column.
Option: + icon button in the "Send Modification" column.

Click on checkbox and give a comment if the result is not correct then click on Confirm button. When the section in charge clicks on the Confirm button then it goes back to the same analyst who sent it after testing.

If the result is correct and the section in charge clicks on the Confirm button, then it will go to the reviewing stage.
