22.3 How To Create Travel Report?
Step 3: Create Travel Report.
For this, go to Create Travel Report menu under Travel Management module then click on Add button.
Figure: Search Modules search box, Create Travel Report, Travel Management module, Add button (represented by a plus sign). A table is visible with columns: Select, Travel Plan ID, City, Travel Date, Customers info, Claim info, Travel Report Status.
Once you click on Add button a popup will appear in which you have to fill necessary details.
Figure: Travel Report popup window. Fields include: Travel ID (dropdown), Travel Date, Actual Return Date, Checkboxes: Travel Claim Required, Is Travel Claim Required. Approved Customer List For Travel Plan(2) table with columns: Customer Name, Address, Contact Name, Departments, Designation, Number, Email. Rejected Customer List(1) table with columns: July, Contact Person Name, Department, Purpose Of Visit, Associated Lab Name For Testing, Rejected Customer, Rejection Comment. A button labeled "SAVE TRAVEL REPORT" is at the bottom left.
In this screen user have to select created Travel ID on the basis on which all generated data against selected travel id will be reflected here. If user wants to make some changes then click on highlighted icon in the below image.
