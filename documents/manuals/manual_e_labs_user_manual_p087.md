20.4 What is App- Role and How To Create It?
First you have to create role for user, user group or group of group. For this, click on App Role tab and then go to Add button.

Figure: "APP ROLE" dialog window.
Field: Name; Value: Client Module- FullAccess.
Field: App Meta Data; Value: [Expandable section].
Field: App Id; Value: [Dropdown menu].
Field: Ref Code; Value: [Text input field].
Field: App Actions List; Value: Checkbox grid.
Option: EXPORT
Option: ADD
Option: EDIT
Option: VIEW
Option: DELETE
Option: ACTIVE
Option: AUDIT_HISTORY
Field: App Resource List; Value: [List area].
Button: UPDATE.

Fill all the required details,
Name- App role name which you want to give.

App Meta Data-
App Id- App Id is basically the company name.
Ref Code- It is indicated to the different branch’s code.

App Action List-
Here you can give permissions by selecting the checkboxes for this role.
