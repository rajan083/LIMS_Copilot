E-labs User Manual, page 100. Source file: E-labs User Manual.pdf.

Figure: Screenshot of the "SAMPLE NO. (6)" dialog, showing a table of descriptions and sample values, with "SAVE" and "CANCEL" buttons at the bottom right.

In the above image tester will have to fill data for the required parameters and then calculation will performed and show result in rest of the parameters.

Figure: Screenshot of "Test Result" section with fields for Result, Equipment Detail, Sample Condition, Specimen Dimension, Specimen Type/Size, Pre-Conditioning, Avg Additional Thickness, Assessment Temp/Time, Parameter Capacity Used, Method of Sample Preparation, Type Of Machine, Velocity Of Impact, Span Length. It also shows a "Part C" header and a dropdown field for "SECTION INCHARGE".

Once you fill all the necessary details set the status by selecting section in charge from the status dropdown so that it can go to the next stage that is section in charge. It will now go to the section in charge in review stage.

Figure: Screenshot of the "Testing & Review" interface showing the grid with status selection dropdowns.

Rest of the steps are same from the Order Process Management only the difference is user can set the status from the dropdown after reviewing it. From the status dropdown user could be select one stage back or one stage forward.
