E-Labs

7.1 What is Packet?

A packet is a sample which the laboratory receives for its testing. It is received by the courier or through the lab representative.

7.2 How To Enter Detail for Packets?

First, we receive packets that must be filled in packet tab. For this, click on Order Management > Packet from the sidebar which is on the left of the screen then the following screen will be appear.

Figure: A dialog box titled "GET INWARD". Fields include: Branch (dropdown), Customer (search field), Place (text field), Customer Address (text field), Sampled by Customer (checkbox), Sampled by ITC (checkbox), Mode Description (text field), Remarks (text field), and a button labeled "SAVE".

In above screen you should fill all the necessary details. For example

Branch- Which branch it is received.
Customer- Customer details must be filled in here.
Place- Customer's place must be filled in here.
Customer Address- Customer's address must be filled in here.
Packet Mode- User can select sampled by customer or sampled by lab depending on the requirement.
