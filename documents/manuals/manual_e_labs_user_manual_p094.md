E-labs User Manual, page 94. Source file: E-labs User Manual.pdf.

For all the club quotations go to Select Quotation section which comes under Sample & Test Information. Click on the ‘+’ icon which is highlighted in the above image. After clicking on this icon following popup will appear.

Figure: Screenshot of the "SELECT QUOTATIONS (1/1)" popup. It contains a table with columns: Select; Quotation Name. It shows a checkbox header, a row for a specific quotation, and a "SELECT QUOTATION" button.

Here all the club quotation will be visible to you and you can select according to your requirement. Once you select the quotation all the parameters against this quotation will auto populated in select parameter section.

Figure: Screenshot of "TEST REQUEST FORM" popup showing the "Select Parameter(2)" section. Columns: Select; Sample Name; Rim Details; Part No./Unit No; Quantity; Measuring Unit For Quantity; Test Parameter; Measuring Unit; Test Method.
Option: Whether Interim Observation / Report Is Required.
    Option: Yes.
    Option: No.
Option: Whether Compliance Statement / Conformity Statement Is Required.
    Option: Yes.
    Option: No.
It shows "If Yes Conformity Statement Will Be Made As Per For G8:09/2019 Guideline On Decision Rules And Statements Of Conformity".

You can see in the above image also you can select the parameters according to your requirement by clicking on the ‘+’ icon. A popup will appear and then you can select accordingly.

Note:- In order booking with TDS, there will be an order book against each of the parameters selected by you in E-TRF form.
