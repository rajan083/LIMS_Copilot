13 What Happens on The Invoicing Stage?

Stage 9- In this step you are on invoicing stage and this denotes your order is ready for generating invoice against the company specified in the invoice list also you can download the report. For this, click on the Add button and fill in all the necessary details and then save. Now this will go into another phase.

Figure: The Invoicing page showing a data table with columns: Action, Sample No, Material No, Branch, Department, Sample Registration Date, Report Date. Each row has action icons including a download report icon. The top toolbar contains a button labeled: Add, and a button labeled: DOWNLOAD. This illustrates the stage where orders are listed and reports can be downloaded.

Click on download report icon to download the report as shows in the above image.

Note: - The user can use custom edits to make any corrections to their order before going ahead with dispatching. Once it gets to the dispatch stage, we cannot make any improvements to parameters or order. Therefore, the user cannot use the report change section while it is in the dispatching phase.
